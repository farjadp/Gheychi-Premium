Restricted access The part nobody else does

Channels that block saving
are still just files.

Telegram lets a channel owner switch off forwarding and saving. Every ordinary downloader stops there, because the Bot API genuinely cannot read those messages.

Gheychi does not use the Bot API for this. It runs a real Telegram user session over MTProto, so a protected post is an ordinary message to it — video, album, document or voice note. You paste the t.me link; it replies with the file.

What you can paste

Public post
t.me/name/123
Private channel
t.me/c/…/123
Forum topic
t.me/c/…/7/123

Albums arrive whole. Invite links (t.me/+…) are not supported yet.

Requires the bot's account to be a member of the channel.

Sequence

Operating sequence

Three steps, all inside Telegram. Nothing to install, nothing to sign up for.

Send the link

Paste any media URL, or a t.me post link, into the chat. The bot reads it and reports what it found.

Pick the quality

Choose a resolution, or take audio only as MP3. Your plan decides which options are open and how many are left this period.

Take the file

It arrives as a normal Telegram file you can forward or save. The server's temporary copy is deleted within the hour.
